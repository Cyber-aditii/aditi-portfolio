## ⚡ Key Interactive Features

The portfolio web application features a custom state-of-the-art cyberpunk HUD theme with several interactive modules:

*   **👾 Global Particle Mesh Background (`CyberMeshBackground`):** Interactive canvas rendering real-time cursor-linked particle networking structures.
*   **🎯 Telemetry Custom Cursor (`CyberCursor`):** A custom SVG vector reticle cursor that snaps, expands, and plays high-fidelity audio on interactive elements.
*   **💻 Interactive Response Terminal (`IntroCard`):** A client-side simulated terminal shell where visitors can type messages and receive real-time, interactive shell script stdout streams.
*   **🔒 WRAITH XSS Engine Showcase (`StatsCard`):** Highlights features of WRAITH XSS—a custom-developed multithreaded subdomain crawler, filter evasion parser, and browser rendering engine.
*   **🎵 Sound FX Engine (`useSound`):** Clean, atmospheric click & hover synthesizers with an integrated toggle button on the header navigation.
*   **📊 Animated Bento Grid Layout (`BentoGrid`):** Responsive grid utilizing GSAP scroll triggers, custom cursor-hover glows, and HUD design accent lines.

## 🚀 Quick Setup & Installation

To run this portfolio website locally:

### 1. Clone the repository
```bash
git clone https://github.com/Cyber-aditii/aditi-portfolio.git
cd aditi-portfolio
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run the development server
```bash
npm run dev
```

The site will be hosted locally at `http://localhost:5173`.

---

## 🔧 Building for Production

To create an optimized production build:

```bash
npm run build
```

This compiles the static assets into the `dist/` directory, which can be deployed to Vercel, Netlify, or GitHub Pages.
